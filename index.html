Переформатор карточек товаров

Вставьте HTML слева → нажмите «Переформатировать» → скопируйте результат справа

Правила

  • Блоки <hl>…</hl> с карточками товаров заменяются на переформатированный код, без обёртки <hl>.
  • Блоки <hl> без карточек остаются нетронутыми.
  • Карточка с описанием → отдельный <product-card> без обёртки.
  • Карточка без описания, одиночная → <product-card> без обёртки.
  • Карточки без описания, чётное число → один <product-card-grid>.
  • Карточки без описания, нечётное число → чётная часть в <product-card-grid>, последняя — отдельным <product-card>.
